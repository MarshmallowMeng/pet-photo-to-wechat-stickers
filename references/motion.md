# 动作设计和返修

## 多角度保真

- 以真实照片核对定妆，记录左右以画面还是宠物自身为准。照片能看到的远耳要保留耳根及可见轮廓，真正被挡住时允许合理遮挡。原照一只耳朵略高时保留自然差异，避开褶皱长成直立尖耳、另一只耳朵凭空消失、硬造对称等错误。
- 先检查脸部尺度、口鼻长短、毛色和毛发质感。相近动作共用同一张母版，顺序连续的动作可用同一参考生成明确格数的精灵表。提示应明确镜头、地面支撑、每格变化以及无字、无编号、格间留白，随后逐格核对。多姿势母版以固定脚底基线和同一比例放进画布；逐格按头高或包围盒重新居中会造成胸、腿随画面缩放。
- 正脸接近一只眼或一只耳被遮挡的角度、伸腿关节角度等缺少参考时，从有把握的角度改写动作。先守住身份和肢体，再追求夸张动势。

## 动作库

用作可选的聊天主题。根据宠物的姿势和用户说法选用。

| 含义 | 推荐动作 | 观察点 |
| --- | --- | --- |
| 哈哈哈 | 笑脸、眯眼、两次很轻的上抬 | 保留笑脸轮廓及固定坐姿 |
| 啊？ | 快速歪头、略停、回正 | 颈侧无叠影，两只耳朵与头同时转 |
| 困了 | 眼皮垂下，张嘴打一个哈欠后收住 | 张合过程中只有一个下颌和一条嘴线 |
| 好哒 | 短促地点头一次 | 动作主要是俯仰，前爪固定 |
| 谢谢 | 稍慢地低头致谢，或叼着同一朵小花低一下头 | 区别于确认式点头；道具始终在原衔接处 |
| 抱抱 | 压低肩膀、两前爪向前撑，可配爱心 | 爪和同侧肩连接，臀部支撑合理 |
| 等一下 | 原来的一只前爪抬起、略停、放回 | 抬起时原落脚位置腾空，另一前爪承重 |
| 马上到 | 侧向或斜侧一步以上的迈步 | 膝和腕连续转动，交叠符合前后景，落脚不穿地 |
| 好耶 | 一次小跳，起落接回同一姿势 | 短而清楚，前爪形状不随跳变 |
| 委屈巴巴 | 趴着把下巴贴在前爪上，抬眼 | 下巴、前爪和背线稳定，眼神集中 |
| 不行 | 坐稳后快速左右摇头一到两轮 | 胸、肩、爪不跟摆；正面经过左右有连续过渡 |
| 无语了 | 侧瞥、半眯，略停 | 表情用眼皮和视线表达，躯干稳定 |
| 早安 | 微笑睁眼，可配小太阳 | 保留原笑脸，避免多余身体起伏 |
| 晚安 | 同一张蜷趴慢慢闭眼，可配小 Z | 头和蜷着的身体停在一个姿势 |

## 返修时优先检查

| 缺陷 | 返修 |
| --- | --- |
| 本来应静止的肩、胸、前爪随头扭动 | 单姿势锁躯干和肩线，运动在头颈处平滑收住。打开活动最远帧看颈侧，检查锁定区在解码后的像素是否一致 |
| 嘴消失、眼睛重影、耳朵错位 | 用同一表情源做局部运动。确需换表情先对齐同一套五官，再在有对应关系的区域补帧 |
| 抬爪出现两只前爪、腿断掉或互换 | 重新设计接地、离地、抬起、落地相位。有缺失时补画对应姿势。单纯帧间混合可能复制或吞掉肢体 |
| 动作慢而中间卡顿 | 先看实际解码的帧延时。缩短停顿，把更多真实中间姿势用在位移最快或受力变化处，再看正向和循环接缝 |
| 和本套其他表情像同一个动作 | 按语义改主动作及节奏，如快点头和带表示感谢的道具与停顿。仍难区分可缩减数量 |
| 多次调整越来越不像原照 | 回看最早已验收的版本，找回清楚的姿势或直接回到参考图，用较简单的动作重新渲染 |

GIF 单帧时长使用 10 ms 刻度。连续重复画面通常会在编码中合并为一次停顿，实际动作要靠形态或位置的有效变化。较高的编码帧数不能保证动作自然。帽子、花梗和背景符号应与宠物运动的层次一致。
